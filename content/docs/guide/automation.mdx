---
title: 网络策略与自动化
description: 按 Wi-Fi SSID 自动切换路由模式，以及它刻意不做的事。
---

**网络策略** 让 ClashMax 在你换 Wi-Fi 时自动调整代理配置：公司网络自动关代理、家里自动开 TUN、咖啡厅自动开系统代理。

入口在 **设置 → 系统 → 网络策略**。

## 一条策略包含什么

| 字段 | 说明 |
| --- | --- |
| 名称 | 便于识别 |
| SSID | 匹配的 Wi-Fi 名称（不区分大小写） |
| 代理路由 | 匹配后切到系统代理 / TUN / NE 代理 |
| 启用系统代理 | 仅在路由为系统代理时有意义 |
| 自动启动运行时 | 匹配后是否顺带把核心拉起来 |

## 没有匹配到策略时

这一档是全局的，两个选项：

- **保持当前状态**：什么都不动。
- **恢复之前状态**：把路由、系统代理、以及「由策略拉起的运行状态」恢复到匹配那条策略**之前**的样子。

第二档意味着策略是**可逆**的：接入公司 Wi-Fi 时策略把你切到直连，离开后自动切回原来的配置，而不是把你留在直连里。

<Callout type="warn">
ClashMax **只应用你自己保存的策略**。没有匹配的策略时，它不会自作主张地切换 TUN 或 NE 代理。这是刻意的——自动改动网络栈的软件必须让用户看得懂它为什么这么做。
</Callout>

## 使用建议

<Steps>
<Step>
### 先只写一条

拿最常用的那个网络开始，路由用系统代理，先别打开自动启动运行时。
</Step>

<Step>
### 用「应用当前」验证

面板里有 **应用当前** 和 **应用此规则**，可以手动触发一次，确认结果符合预期，再打开自动应用。
</Step>

<Step>
### 全局默认选「恢复之前状态」

这样每条策略都是可逆的，你不会因为忘了某条策略而莫名其妙处在错误的路由模式下。
</Step>

<Step>
### 想更快，绑一个快捷键

全局快捷键里有 **应用当前网络策略**，可以在任何时候手动重新求值一次。
</Step>
</Steps>

## SSID 读不到的时候

macOS 对读取 Wi-Fi 名称有权限限制。策略面板里有 **解析当前网络 SSID 可用性** 的动作和对应的状态提示——如果它说读不到 SSID，策略就无法匹配，需要按提示授予定位权限（macOS 把 SSID 归在位置信息下）。
