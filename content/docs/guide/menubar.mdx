## 菜单栏面板

日常操作大多不需要打开主窗口。菜单栏面板提供：

- 运行状态与所有者（用户态 / TUN helper / Network Extension / 预览）
- 实时流量图
- **启动核心** / **停止核心**
- **运行模式** 切换（规则 / 全局 / 直连）
- **代理模式**（代理路由）切换
- 系统代理开关（仅在系统代理路由下有意义）
- 置顶代理组的节点切换
- 检查更新

面板会直接说明当前谁在接管路由，比如「Network Extension 正在接管透明代理路由」「TUN helper 接管 VPN 式路由」。

### 置顶代理组

最多可以置顶 **3 个** 代理组，让它们直接出现在菜单栏面板里。选常用的那几个——比如一个主选择组加一个流媒体组——切换就不用开主窗口了。

### 菜单栏图标

图标旁默认显示实时上下行速度。**设置 → 通用 → 菜单栏流量速度** 关掉后只剩 ClashMax 图标；这只影响显示，流量统计和面板里的流量图不受影响。

## 启动行为

**设置 → 启动**：

| 选项 | 作用 |
| --- | --- |
| **登录时启动** | 注册为 macOS 登录项 |
| **静默启动** | 开机启动时不显示主窗口，只留在菜单栏 |
| **登录项状态** | 显示当前注册状态，可直接跳到系统设置 |

<Callout>
静默启动**只对登录项启动生效**。你自己手动打开 ClashMax 时，主窗口一定会出现。
</Callout>

## 全局快捷键

需要先打开 **开发者模式**，然后在 **设置 → 快捷键** 里录制。可绑定的动作：

| 分类 | 动作 |
| --- | --- |
| 运行控制 | 启动 / 停止核心、启动、停止、重启核心 |
| 运行模式 | 规则模式、全局模式、直连模式 |
| 代理路由 | 系统代理路由、TUN 路由、NE 代理路由 |
| 系统代理 | 切换系统代理 |
| 其他 | 更新全部订阅、应用当前网络策略、打开主窗口 |

快捷键是全局的：任何 App 在前台时都有效。设置页会显示每个绑定的注册状态，冲突或注册失败会明说。

<Callout>
最值得绑的两个是**切换系统代理**和**直连模式**——某个网站在代理下打不开时，一个热键切直连比翻菜单快得多。
</Callout>
