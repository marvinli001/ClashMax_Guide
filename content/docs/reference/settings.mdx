标 <span title="需要开发者模式">**·开发**</span> 的项目需要先打开 **通用 → 开发者模式**。

## 通用

| 选项 | 说明 |
| --- | --- |
| 开发者模式 | 显示 helper 诊断、外部控制器选项和高级恢复细节 |
| 菜单栏流量速度 | 菜单栏图标旁显示实时上下行；关掉只影响显示，不影响统计 |
| 外观 | 跟随系统 / 浅色 / 深色 |
| 语言 | 显示当前语言，并跳转到 macOS 的「语言与地区」按 App 设置 |

## 备份与恢复

| 选项 | 说明 |
| --- | --- |
| 导出 | 可选是否包含加密机密（需设密码） |
| 恢复 | **核心运行时不可用**，必须先停止 |

详见[备份与迁移](/docs/guide/backup)。

## 更新

| 行 | 内容 |
| --- | --- |
| App Package | App 版本与构建号，可手动检查更新 |
| Bundled Core | 随包内置的 Mihomo 版本 |

## 启动

| 选项 | 说明 |
| --- | --- |
| 登录时启动 | 注册为 macOS 登录项 |
| 静默启动 | 仅对登录项启动生效，不显示主窗口 |
| 登录项状态 | 显示状态并跳转系统设置 |

## 快捷键 ·开发

全局快捷键录制与注册状态。可绑定的动作见[菜单栏与快捷键](/docs/guide/menubar#全局快捷键)。

## 运行时

| 选项 | 说明 |
| --- | --- |
| 混合端口 | Mihomo 的 HTTP + SOCKS 入站端口 |
| 控制器端口 | 本地控制 API 端口，绑定 `127.0.0.1` |
| Allow LAN | 允许局域网设备使用代理端口 |
| IPv6 | 在运行时配置里启用 Mihomo 的 IPv6 支持 |
| 启用 DNS 覆盖 | 把 App 管理的 DNS 选项写进运行时配置 |
| 延迟测试模式 | Mihomo URL 延迟 / 原生 Ping |
| 统一延迟 | 测两次握手只报第二次，排除建链开销 |
| 外部控制 ·开发 | 外部面板接入相关选项 |
| 日志级别 | Info / Warning / Error / Debug |

<Callout type="warn">
混合端口和控制器端口在 **NE 代理**模式下修改需要重启运行时——隧道在启动时就固定了它们。见[变更生效模型](/docs/advanced/apply-model)。
</Callout>

## 订阅

| 选项 | 说明 |
| --- | --- |
| User Agent | 抓订阅时发送的客户端标识 |
| 请求超时 | 每次抓取尝试的网络超时 |
| 使用本地 Clash 代理 | 直连失败后，改用 `127.0.0.1` 上当前的混合端口重试 |
| 使用系统代理 | 直连失败后，改用 macOS 当前的系统代理重试 |
| 忽略 TLS 错误 | 允许证书无效的订阅服务器，**仅用于可信面板** |
| 自动更新 | 按「每配置策略 → 远端元数据 → 全局回退间隔」刷新 |
| 默认订阅间隔 | 订阅未公布 `profile-update-interval` 时的回退间隔 |
| 后台检查间隔 | ClashMax 多久醒来检查一次是否有订阅到期 |
| 重试退避上限 | 连续失败后的最大延迟 |
| 更新失败通知 | 自动刷新失败时发 macOS 通知 |

## 规则

| 选项 | 说明 |
| --- | --- |
| 规则覆盖 | 全局的前置 / 后置 / 禁用规则 |
| Geo 数据库 | 自动更新开关、更新间隔、geodata 模式、geox URL，可立即更新 |

<Callout>
Geo 数据库放在「规则」而不是「网络」下，是因为 `GEOSITE` / `GEOIP` 规则匹配的正是这些数据。

这些键由 App 管理而非从配置透传：否则核心只会在第一次需要时下载一次，之后永不刷新，你的 geo 规则会一直匹配一份越来越旧的快照。
</Callout>

## 系统

| 选项 | 说明 |
| --- | --- |
| 代理路由 | 系统代理 / TUN / NE 代理，**启动时生效** |
| 网络策略 | 按 Wi-Fi SSID 自动切换，见[网络策略](/docs/guide/automation) |
| TUN Helper 状态 | 仅 TUN 模式显示；注册、修复、查看诊断 |

系统代理模式下这里会明说：不需要特权 helper；想给非 HTTP 流量做 VPN 式路由才需要切到 TUN。

## NE 代理

仅在代理路由为 NE 代理时出现。

| 行 | 内容 |
| --- | --- |
| 系统扩展 | 安装 / 激活状态与操作 |
| 透明代理状态 | 隧道当前状态 |
| NE 诊断 | 汇总诊断，可刷新 |

## 首页上的两个面板

有两组设置不在设置页，而在首页：

- **系统代理设置**：代理主机、默认绕过、自定义绕过、校验绕过条目、代理守卫与守卫间隔（5~600 秒）
- **TUN 设置**：协议栈、设备名、`auto-route`、`strict-route`、`auto-detect-interface`、DNS 劫持、MTU、排除路由网段，以及 Fake IP 与整套 DNS 覆盖
