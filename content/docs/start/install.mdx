## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 15 或更高 |
| 芯片 | Apple Silicon 或 Intel（内核是 universal 二进制） |
| 权限 | 只有 TUN 模式和 NE 代理需要额外的系统授权 |

## 安装步骤

<Steps>
<Step>
### 下载 DMG

打开 [最新 Release](https://github.com/marvinli001/ClashMax/releases/latest)，下载 `ClashMax-X.Y.Z.dmg`。

同一个 Release 里的 `ClashMax-X.Y.Z.zip` 是给应用内 Sparkle 自动更新用的，不是手动安装包。
</Step>

<Step>
### 拖进 Applications

打开 DMG，把 `ClashMax.app` 拖到窗口里的 `Applications` 快捷方式上。
</Step>

<Step>
### 从 /Applications 启动

推出 DMG，从 `/Applications` 启动。
</Step>
</Steps>

<Callout type="warn">
必须从 `/Applications` 运行。特权 helper 授权和 Network Extension 都会校验 App 的安装位置，直接在 DMG 里或从「下载」文件夹运行会让授权流程失败。位置不对时 ClashMax 会提示，也可以让它自己复制过去。
</Callout>

## 更新

**设置 → 更新** 里可以检查 App 更新，走的是 Sparkle。每个 App release 都带着匹配的 Mihomo 稳定版内核，升级 App 就等于升级内核。同一处显示两行：

- App Package：App 版本与构建号
- Bundled Core：随包内置的 Mihomo 版本

## 卸载

1. 停止运行时，把代理路由切回系统代理，这样系统代理设置会被恢复。
2. 退出 ClashMax，把 `/Applications/ClashMax.app` 移到废纸篓。
3. 注册过 TUN helper 的话，去 **系统设置 → 通用 → 登录项与扩展** 移除对应条目。
4. 删除 `~/Library/Application Support/ClashMax/`，配置、运行时产物和日志都在里面（[文件与路径](/docs/reference/paths)）。

订阅 URL 存在 Keychain 里，介意残留的话在「钥匙串访问」搜 ClashMax 手动删。
