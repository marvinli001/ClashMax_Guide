主窗口左侧是固定的九个页面，分成看状态、改配置、查问题三类。

| 页面 | 职责 | 什么时候来 |
| --- | --- | --- |
| 首页 | 运行控制，以及是否真的在代理 | 启停核心、切运行模式、发现异常 |
| 状态 | 只读诊断详情 | 首页提示有问题，来这里看具体事实 |
| 配置 | 配置文件与订阅管理 | 导入、更新订阅、改 provider 选项 |
| 代理 | 代理组与节点 | 换节点、测延迟、跑 provider 健康检查 |
| 连接 | 实时连接列表 | 查某个 App 走了哪条链路 |
| 路由 | 运行时片段库 | 加规则、打 DNS 补丁、写原始 YAML |
| 规则 | 当前生效的规则列表 | 确认某条规则在不在、排第几 |
| 日志 | 运行时日志流 | 核心报错、连接失败的一手信息 |
| 设置 | App 与运行时选项 | 端口、路由模式、备份、更新 |

## 几个容易混的边界

### 首页和状态

首页回答「现在正常吗、要不要处理」，只在出问题时列条目。状态页回答「具体是什么情况」，把运行时、DNS、规则覆盖、helper、TUN/NE 诊断分组摊开，还能复制一份已脱敏的诊断报告。

### 规则和路由

规则页是只读的，显示核心当前实际加载的规则，包括来自 rule-provider 的。编辑在路由页，你写的东西会被合成进运行时配置，之后才出现在规则页。

想从一条连接反查规则，在连接页选中它点「为何命中此规则」。要为它新增规则，点「在『路由』页打开」。

### 代理和连接

代理页是「我可以选什么」，连接页是「实际发生了什么」。节点选对了但连接页显示走了 DIRECT，问题在规则不在节点。

## 菜单栏

菜单栏面板是主窗口的轻量版：运行状态、流量图、运行模式、常用代理组切换、检查更新。日常大多数时候不用打开主窗口。菜单栏图标旁默认显示实时上下行速度，可以在 **设置 → 通用 → 菜单栏流量速度** 关掉。细节见[菜单栏与快捷键](/docs/guide/menubar)。

## 开发者模式

**设置 → 通用 → 开发者模式** 打开后会多出全局快捷键设置、helper 诊断与日志、外部控制器选项，以及订阅的旧版 raw provider 过滤器和自定义请求头。

<Callout>
覆盖 Mihomo 键不需要开发者模式。用[路由页的原始 YAML 片段](/docs/advanced/snippets)，它有完整的预检和回滚。
</Callout>
