## 三条基本设定

### 导入的配置不会被改写

你的 YAML 原样存在本地。ClashMax 在启动前另外生成一份运行时配置，端口、controller、secret、DNS、TUN、运行模式都写在那一份里。在 App 里改的东西不会污染订阅原文。

### 内核随 App 分发

Mihomo 核心内置在 App 包里，版本跟着 App release 走。不用自己下载或升级 core 二进制，App 里也没有切换 core 通道的开关。

### 控制面只在本机

Mihomo 的 controller 默认只监听 `127.0.0.1`，每次启动生成新的 secret，App 用 Bearer 认证访问。配置、代理组、连接、日志都是从这条本地通道拿的。

<Callout type="warn">
分享日志、截图或配置前，先去掉订阅 URL、节点凭据和私有域名。
</Callout>
